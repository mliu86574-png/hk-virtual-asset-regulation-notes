# Glossary · 术语表

| English | 中文 | Meaning 含义 |
|---|---|---|
| AMLO | 《打击洗钱及恐怖分子资金筹集条例》 | The ordinance under which VATPs, the four new VA licences and DPMS registration sit 虚拟资产平台、新四类牌照和贵金属交易商登记的法律依据 |
| SFO | 《证券及期货条例》 | Governs securities, including security tokens and tokenised funds 监管证券、证券型代币和代币化基金 |
| VATP | 虚拟资产交易平台 | Centralised exchange licensed by the SFC 证监会发牌的中心化交易所 |
| VA | 虚拟资产 | Digital representation of value that is not a security, e.g. BTC, ETH 非证券类的数字价值载体 |
| Specified stablecoin | 指明稳定币 | Fiat-referenced stablecoin regulated under Cap. 656 受第 656 章监管的法币稳定币 |
| Type 1 / 4 / 7 / 9 | 1 / 4 / 7 / 9 号牌 | Dealing in securities / advising on securities / automated trading services / asset management 证券交易 / 证券咨询 / 自动化交易服务 / 资产管理 |
| PI | 专业投资者 | Professional investor, e.g. individuals with portfolios of at least HK$8 million 如投资组合达 800 万港元的个人 |
| DPMS | 贵金属及宝石交易商 | Dealers in precious metals and stones, registered with C&ED 向海关登记 |
| CIS | 集体投资计划 | Collective investment scheme; public offers need SFC authorisation 公开发售需证监会认可 |
| Staking | 质押 | Locking tokens to help secure a proof-of-stake network in return for rewards 锁定代币参与权益证明网络以获取奖励 |
| Shared order book | 共享订单簿 | A licensed VATP matching orders with an overseas affiliate's book 持牌平台与海外关联平台合并撮合 |
| Travel rule | 旅行规则 | Passing originator and beneficiary information with VA transfers 转账时传递汇款人和收款人信息 |
| PoR | 储备证明 | Proof of reserves: evidence that a token's backing assets exist 证明代币底层资产存在 |
| RWA | 现实世界资产 | Real-world assets represented on-chain 链上代表的现实世界资产 |
| LEAP | — | Policy Statement 2.0 framework: Legal, Expanding, Advancing, People 《政策宣言 2.0》框架 |
| ASPIRe | — | SFC roadmap: Access, Safeguards, Products, Infrastructure, Relationships 证监会路线图 |
